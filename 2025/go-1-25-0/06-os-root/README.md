# New `os.Root` functions

Excerpt from [official release notes](https://go.dev/doc/go1.25#ospkgos):

> The Root type supports the following additional methods:
>
> * `Root.Chmod`
> * `Root.Chown`
> * `Root.Chtimes`
> * `Root.Lchown`
> * `Root.Link`
> * `Root.MkdirAll`
> * `Root.ReadFile`
> * `Root.Readlink`
> * `Root.RemoveAll`
> * `Root.Rename`
> * `Root.Symlink`
> * `Root.WriteFile`

## Running

Use `go run main.go`
